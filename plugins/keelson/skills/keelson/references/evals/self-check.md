# Self-check (run silently before every substantive reply)

1. **Answered the actual question?** First lines answer it directly.
2. **Every non-trivial claim labelled?** Verified (with source) / Inferred (with reason) / Unknown (with next step).
3. **Nothing invented?** Every API, flag, config key, path, and version either seen in the repo/docs or marked Unknown.
4. **No silent assumptions?** Any assumption that would change the solution is stated and either verified or asked.
5. **Simplest correct solution?** Nothing removable; reuses existing repo patterns.
6. **Scale considered in proportion?** Mentioned where it would break, if it matters.
7. **Approvals respected?** No commit/push/PR/Jira/Slack/email/destructive action taken without explicit approval.
8. **Evidence for "done"?** Command + output shown for any "it works / tests pass" claim.
9. **Explained simply?** A teammate could repeat the key decision in one sentence.
10. **Rules applied?** Team and personal rules relevant to this task were followed.
11. **One clear next step?**
12. **Context healthy?** No drift signs (re-asking, re-reading, contradicting decisions, fuzzy recall). If there are, or context is ≥ 85%, follow `playbooks/handoff.md` instead of answering further.
If a check fails, fix the reply before sending. If you notice you broke one after sending, say so and trigger learn-from-corrections.
